## Project Overview
Pinacle Luxe Web Frontend - A web application project.

## Permissions Policy

**Permission Required Before Making Changes:**

- Installing dependencies
- Deleting files or directories
- Modifying configuration files (package.json, env files, etc.)
- Making changes to multiple files at once
- Changes that affect multiple components or modules
- Any infrastructure or build configuration changes
- Pushing to remote repositories or creating commits

**Permission NOT Required (Proceed Directly):**

- Fixing typos in a single file
- Small, focused changes to one file that are clearly correct
- Running linters, formatters, or build scripts
- Reading files for understanding
- Running tests

**When in doubt, ask first.**

## Commands

- `npm install` - Install dependencies
- `npm run dev` - Start development server
- `npm run build` - Build for production
- `npm run lint` - Run linting
